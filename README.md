# CO2 Web Page Tracker

## Описание

**CO2 Web Page Tracker** — это iOS-приложение, разработанное для анализа, отслеживания, сохранения и управления экологическим воздействием посещаемых веб-страниц. Приложение оценивает выбросы CO2 и потребление энергии веб-страниц, предоставляя пользователям информацию для более экологичного веб-серфинга. Пользователи могут сохранять поисковые запросы, добавлять скриншоты веб-страниц, делиться результатами и рассчитывать количество энергии, потребляемой при посещении веб-страниц.

## API

Приложение использует API [Website Carbon](https://api.websitecarbon.com/#site-endpoint) для получения данных о выбросах CO2 и потреблении энергии.

## Технологии

- **Хранение данных**:
  - `Core Data` — Локальное хранение данных о веб-страницах.
  - `.plist` — Хранение описания JSON параметров.
  - `UserDefaults` — Хранение значений UIStepper.

- **Сетевой слой**:
  - `URLSession` — Работа с сетью, обработка ошибок и проверка интернет-соединения с помощью `NetworkMonitor`.

- **Архитектура и паттерны**:
  - `MVP` + `Coordinator`
  - `Singleton`
  - `Flyweight`
  - `Delegate`
    
- **Интерфейс**:
  - `UIKit`
  - Все экраны организованы с использованием `UITabBarController` для удобной навигации между ними.

## Функциональность

### Экран 1 (Поиск)

- Ввод URL страницы для проверки углеродного следа.
- Отображение прогресса обработки и анализа веб-страницы.
- Сообщение об ошибке при неудачной обработке.
- Обработка отсутствия интернет-соединения.
- Переход на экран деталей/результата анализа веб-страницы при успешной обработке.
- Загрузка продолжается в фоне, может быть приостановлена и возобновлена с сохранением прогресса, а также отменена.

### Экран 2 (Список сохранённых веб-страниц)

- Редактирование и удаление элементов списка.
- Для управления списками данных на экране используется UIFetchResultController, который позволяет автоматически обновлять интерфейс пользователя при изменении данных, обеспечивая плавное и эффективное взаимодействие.

### Экран 3 (Детали веб-страницы / Результат поиска)

- Просмотр деталей веб-страницы.
- Прикрепление скриншота веб-страницы.
- Расчёт воздействия веб-страницы на окружающую среду при 1, 10, 100, 1000 посещениях с использованием `UIStepper`.
- Переход по ссылке на сайт [Website Carbon](https://websitecarbon.com) для получения более детальной информации о методах подсчёта CO2.
- Возможность поделиться результатом.

### Экран 4 (WebKit)

- Просмотр подробностей расчета эко-параметров веб-страницы.

## Планы развития

- Локальные уведомления: устанавливать напоминания для уменьшения посещений экологически вредных сайтов.
- Сортировка сохранённых веб-страниц по дате и CO2 параметрам.
- Добавление тестов.
- Локализация на нескольких языках (русский, английский, испанский).
